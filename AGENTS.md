# HorizonTechX Image Gallery

Internship task project (Horizon TechX). A responsive image gallery with category filters.

## Stack
- Plain HTML, CSS, JavaScript. No frameworks, no build tools, no npm.
- Files: index.html, css/style.css, js/script.js

## Deploy
- GitHub Pages: https://anasamin822-dotcom.github.io/HorizonTechX_ImageGallery/
- Repo: https://github.com/anasamin822-dotcom/HorizonTechX_ImageGallery
- Push to main = live. Ask before pushing or deploying.

## Rules
- Keep the existing visual identity (particle canvas, glass header, Plus Jakarta Sans).
- Images use Picsum with fixed IDs per category - do not replace with random sources.
- Mobile-first, keep accessibility attributes intact.
