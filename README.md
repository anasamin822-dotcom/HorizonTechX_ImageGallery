# HorizonTechX_ImageGallery

A responsive, high-performance image gallery built with pure vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Modern Glassmorphic Dark UI**: Custom-tailored dark theme with subtle glows, glassmorphism cards, and fluid typography.
- **Canvas Particle Network**: Lightweight 2D canvas drawing connecting particles that react gently to cursor movement, automatically pauses when tab is hidden, and disables under `prefers-reduced-motion`.
- **Responsive Layout**:
  - Desktop: 4 columns
  - Tablet: 2 columns
  - Mobile: 1–2 columns
- **Interactive Lightbox Modal**:
  - Full-resolution preview with loading indicator.
  - Previous / Next buttons and keyboard navigation (Left/Right arrow keys).
  - ESC key and backdrop click to close.
  - Dynamic image counter (e.g. `1 / 12`) and full captions.
  - Touch swipe support (left/right) on mobile.
- **Category Filter**:
  - Smooth filtering across *All*, *Nature*, *City*, *Architecture*, and *Animals*.
- **Accessibility**:
  - Semantic HTML elements.
  - ARIA attributes and focus management for keyboard users.
  - Image lazy loading with fixed dimensions to prevent layout shifts.

## Getting Started

No build tools or servers required. Simply open `index.html` in any modern web browser or double-click the file.
